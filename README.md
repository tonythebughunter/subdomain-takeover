## Subdomain Takeover Tool

# Usage

## Clone the repo
    git clone https://github.com/tonythebughunter/subdomain-takeover
## naviagate to the directory
    cd subdomain-takeover
## install requirements
    pip install -r requirements.txt
## run the script
    python takeover.py domains.txt


## If you run into issues while installing requirements, setup a virtual environment
    python -m venv env
## activate the environment
    source env/vin/activate
## Now you can install the requirements
    pip install -r requirements.txt
